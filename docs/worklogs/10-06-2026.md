## Account Linking Implementation (Phases 0-2 + Bugfixes)

### Phase 0 — Manual Test (abort/retry với ManagedLoginV2)

**Mục tiêu:** Xác nhận Cognito ManagedLoginV2 có redirect về callback URL với error param khi PreSignUp Lambda abort flow hay không.

**Kết quả:** URL trả về:
```
http://localhost:5173/?error_description=PreSignUp+failed+...&state=...&error=invalid_request
```
→ ✅ ManagedLoginV2 vẫn trả error params. Có thể dùng URL detection để trigger retry.

**Phát hiện:**
- Hub event `signInWithRedirect_failure` fire trước khi React mount → không dùng được cho retry
- URL param detection là cách đáng tin cậy hơn (module-level, chạy trước `Amplify.configure()`)
- `exports is not defined` là do AWS Console dùng ESM (`.mjs`). Dùng `export const handler` thay vì `exports.handler`

### Bugs & Fixes

#### Bug 1: Circular dependency — nested stacks
```
auth → function (PreSignUp trigger)
function → auth (USER_POOL_ID env var)
         ↕
AuthApi → auth + function (authorizer + integrations)
```
**Fix:** Thêm `resourceGroupName: 'auth'` trên cả 3 `defineFunction` → đưa functions vào cùng stack với auth.

#### Bug 2: Circular dependency — single stack (sau khi fix Bug 1)
```
Lambda → UserPool (sourceArn + env var USER_POOL_ID)
UserPool → Lambda (trigger functionArn)
```
**Fixes:**
- Removed `sourceArn` từ `addPermission` — chỉ specify principal
- Removed `addEnvironment('USER_POOL_ID', ...)` — parse `userPoolId` từ JWT `iss` claim trong handler
- Removed unused `userPoolId` variable

#### Bug 3: Missing npm package
```
FailedToBundleAsset — @aws-sdk/client-cognito-identity-provider not resolvable
```
**Fix:** `npm install @aws-sdk/client-cognito-identity-provider`

#### Bug 4: Google account picker xuất hiện ở lần retry
**Fix:** Thêm `options: { prompt: 'none' }` trong `executeRetry()`

#### Bug 5: Initiate Google link (Settings) dùng sai function
SettingsPanel import `initiateGoogleSignIn` — đúng. Đã remove duplicate `initiateGoogleLink`.
