## 1. Một loader duy nhất — `shared/env.py`

mà cũng không quên được.

Biến môi trường thật **luôn thắng** (`override=False`): container/systemd truyền
config là setup đúng, một file `.env` sót trên image không được phép đè.

Không tìm thấy file thì **warn, không raise** — Docker/CI cấp config qua biến môi
trường là hợp lệ, raise sẽ giết đúng những setup đúng. Chỗ **phải** kêu to là chỗ
gây thiệt hại, và giờ nó kêu:

```
No VVA_PG_DSN / POSTGRES_DSN set and no dsn in langgraph.yaml — falling back to
the LOCAL database (...). Configuration source: ... If you meant to use the
managed database, this is the bug.
```

Trước đây dòng này **hoàn toàn im lặng**.
