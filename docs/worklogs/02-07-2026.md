## P1 — Embedding loads offline (kill HF-Hub round-trips)

**Files changed:**
- `agenticRAG/langgraph_agents/shared/embedding.py` — added `import os`; lazy-load
  property now reads `EMBEDDING_ALLOW_DOWNLOAD` env and passes
  `local_files_only=(_offline)` to `SentenceTransformer`.
- `agenticRAG/langgraph_agents/core/resource_guard.py` — same pattern in
  `shared_embedder()` (line ~142).
- `docs/RUNBOOK.md` — added `EMBEDDING_ALLOW_DOWNLOAD` row to Environment toggles
  table: unset = offline cache only; `1` = one-time download for fresh machines.

**Default:** offline (no HF-Hub calls on restart). Set `EMBEDDING_ALLOW_DOWNLOAD=1`
once on a clean machine then unset for production.

## P2 — Hard-cap retriever ⇄ tools loop at 2 rounds

**Files changed:**
- `agenticRAG/langgraph_agents/state.py` — added `retriever_rounds: int` to
  `AgentState` (with docstring explaining per-turn hard ceiling choice).
- `agenticRAG/langgraph_agents/nodes/retriever_agent.py` — increments
  `current_rounds = state.get("retriever_rounds", 0) + 1` and returns
  `retriever_rounds: current_rounds` in both success and error paths.
- `agenticRAG/langgraph_agents/routing.py` — `route_after_retriever` now reads
  `state.get("retriever_rounds", 0)` and forces → `synthesizer` (or `kimodo` if
  `needs_motion`) when `retriever_rounds >= MAX_RETRIEVER_ROUNDS (2)`, before
  checking last message tool_calls. Renamed `_MAX_TOOL_ROUNDS` →
  `MAX_RETRIEVER_ROUNDS` (exported).

**Design choice (logged here per spec):** counter is a **hard per-turn ceiling** —
it is never reset within a turn, including on grader-triggered retry. A grader retry
re-enters `retriever_agent` which increments `retriever_rounds`; if rounds hit 2
before the grader retry, synthesizer is forced. Simplest correct choice: prevents
runaway loops even across retry paths. A future optimization could reset the counter
on grader entry if we want to give the retry a clean 2-round budget.

## P3 — Enforce web_search toggle at ALL layers

**Files changed:**
- `agenticRAG/langgraph_agents/nodes/retriever_agent.py`:
  1. **Conditional prompt** — replaced static `_RETRIEVER_SYSTEM_PROMPT` with
     `_build_retriever_system_prompt(web_search_enabled=...)` that conditionally
     injects `_WEB_SEARCH_TOOL_BLOCK` and `_WEB_SEARCH_RULE_LINE`. When off, the
     LLM is never told `search_medical` exists.
  2. **Default fixed** — `config["configurable"].get("web_search", False)` now
     defaults `False` (was `True`). Aligns with `schemas.py:12` product intent.
- `agenticRAG/langgraph_agents/graph.py`:
  1. **Execution guard** — `_make_guarded_tools_node(base_tool_node)` wraps
     `ToolNode` in a custom async node. When `web_search=False` and the last
     `AIMessage` contains a `search_medical` tool_call, it short-circuits with a
     synthetic `ToolMessage(content='{"blocked": "web_search_disabled"}')`. All
     other tool_calls (kb_search, memory_search, etc.) pass through to ToolNode
     unchanged. `ToolNode(all_tools)` is now wrapped: `_make_guarded_tools_node(ToolNode(all_tools))`.

**Defense-in-depth layering:**
- Layer 1 (prompt): LLM never sees `search_medical` when off.
- Layer 2 (guard): Even if LLM hallucinates the call, execution is blocked.
- `kb_search`, `memory_search`, `resume_last_session`, `youtube_transcript`
  completely unaffected by the toggle.
