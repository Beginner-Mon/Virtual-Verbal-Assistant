## What held up

The schema work was solid and in places went past its own plan. 009 shipped a
`downgrade()` the plan never asked for; the row seed moved out of
`POST /me/memory` — where a user who never wrote a memory would have had no
preferences row — into a lazy upsert on the endpoint itself.

The PHI boundary (Q10) is the decision worth keeping: `user_preferences` holds
UI only, clinical facts stay in `user_memory` with its `valid` flag. That one
survives into v3 unchanged, only enforced differently.

Lazy-loading one character instead of the whole catalog (`863458d` §B) is also
correct and stays — including the follow-up fetch when a different character is
picked, which the plan did not mention and the implementation got right anyway.

## What did not

Recorded here because the fixes land in [[03-09-2026]] and the reasons belong
next to the work that caused them:

- **Neither plan had a deployment step.** `/me/preferences` was never added to
  `rest_api_stack.py`. Nothing shipped: these commits are on
  `feat/user-preferences` only, and neither `origin/main` nor `origin/release`
  contains them — so this is a latent fault, caught before a deploy rather than
  in one. Had it deployed as it stood, API Gateway would have answered every
  call 403 and the frontend, which reads any failure as "guest", would have
  fallen back to localStorage without saying anything. It worked against a local
  uvicorn and would have worked nowhere else.
- **The characters optimisation landed in the wrong file.** `routes_characters.py`
  says in its own docstring that it is the local dev shim; production runs
  `infra/lambda/characters/handler.py`, which kept returning all nine columns.
- **`SELECT 1 ... AND is_active` was removed** in favour of catching a foreign
  key error. A foreign key cannot see `is_active`, so a disabled character
  became settable as a default.
- **FOUC was fixed in one direction only.** The blocking script falls back to
  `prefers-color-scheme`; `main.tsx` passes `defaultTheme="light"`. A dark-mode
  machine painted dark, then React repainted light.
- **`useUserPreferences.ts` was written and never imported** — including the
  300ms debounce that Q7 had settled on. Deduplication was done instead with a
  module-level promise that carried one caller's `AbortSignal`.
