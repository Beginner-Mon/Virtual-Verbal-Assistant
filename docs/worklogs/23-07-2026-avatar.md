## Phase B — Idle + Eyes
- `EyeController.ts` — drive `vrm.lookAt` qua yaw/pitch trực tiếp (`autoUpdate=false`, setter
  đánh dấu dirty → `vrm.update` áp dụng qua applier, đúng cả bone lẫn expression-based). Mouse
  input normalized [-1..1] → yaw ±22°/pitch ±12°, smoothing exponential frame-rate independent.
  Mouse thắng wander trong 2s gần nhất.
- `IdleBehaviorController.ts` — chỉ chạy khi IDLE. Emotion wanderer luân phiên rest↔micro-emotion
  (luôn qua neutral), weighted happy/relaxed, intensity 0.15-0.4, interval 4-9s. Gaze wanderer
  saccade ±0.3 mỗi 2-5s (35% về center). Drive expression/eye trực tiếp → không refresh engagement.
- `AvatarController` mở rộng: engagement deadline (`EVENT_GRACE 3s`, `TTS_GRACE 1.5s`), arbitration
  ENGAGED↔IDLE, cross-fade emotion→neutral 800ms khi vào idle (§1.3). Glue: `CharacterViewer`
  thêm `onMouseMove` → `setMouse`.

## Phase C — Lip sync (Mode 1 amplitude)
- `LipSyncController.ts` — mixer contributor chạy SAU emotion (override mouth viseme `aa`+`ou`).
  Đọc RMS từ AnalyserNode mỗi frame → open weight, attack nhanh (40/s) release chậm (12/s),
  frame-rate independent. Mode 2 (phoneme) chỉ để interface, không build (VieNeu không xuất phoneme).
- `lipSyncAudio.ts` — `analyserFromElement` (đường tts.audio thật) + `playSyntheticSpeech` (tone
  LFO 4.5Hz mô phỏng âm tiết cho DevPanel test, không cần file wav). AudioContext resume sau gesture.
- Engagement: lip sync đang phát → giữ ENGAGED; ended → grace 1.5s.
- DevPanel thêm nút "Speak (test lip-sync)" + hiển thị mode engaged/idle.
