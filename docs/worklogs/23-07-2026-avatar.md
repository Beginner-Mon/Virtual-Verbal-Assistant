## Verify live (Playwright, backend không cần)
- tsc 0 lỗi; `vite build` 0 lỗi (33s).
- **Degradation** (model mặc định tình cờ là bronya_long, 0 blendshape): warn "missing 11
  channels, will no-op", `hasCapability=false`, **không crash** — đúng tiêu chí khó nhất Phase A.
- **Emotion render** (switch sang seele qua UI, đọc weight thật qua debug hook):
  happy→0.8 sạch, sad→0.8 sau interrupt (không kẹt happy). seele warn đúng "missing 1: surprised".
- **Cross-fade curve** (drive 1500ms, sample 100ms): `[0.015,0.12,0.397,0.79,0.959,0.999,1...]`
  — đúng S-curve easeInOutCubic, monotonic. Frame-rate independent (§8 rule 5) đạt.
- **Interrupt no-snap**: happy→sad giữa chừng: happy `0.97→0.82→0.47→0.10→0`, sad
  `0.03→0.18→0.53→0.90→1`, tổng luôn ~1 — cross-fade bù trừ, không snap về 0.
- **Blink**: headless Chromium chỉ chạy R3F ~4fps (frame gap 276ms) khi idle → pulse blink
  150ms là sub-frame nên KHÔNG hiện qua browser test (không phải bug — timer vẫn fire, verify
  qua debugBlink thấy reset đúng chu kỳ). Verify logic ở **60fps thật bằng unit test Node**
  (BlinkController không có browser dep): 20s → **4 blink, peak weight 0.985** (≈ sin(π/2)),
  interval trong khoảng 2-6s. Logic đúng; ở browser user thật (60fps) blink hiện bình thường.
