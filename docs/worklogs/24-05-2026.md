## K Final Review

### Bug critical phát hiện sau commit (C1 — MCP subprocess Python interpreter)

Integration test fail: `McpError: Connection closed` + stderr:
```
C:\Users\Nguyen\AppData\Local\Programs\Python\Python312\python.EXE:
ModuleNotFoundError: No module named 'langgraph_agents'
```

**Root cause**: `config/mcp_servers.yaml` dùng `command: python` → subprocess bốc **system Python 3.12** thay vì firstconda env Python → không tìm thấy package.

**Impact**: production `uvicorn` start crash vì `build_graph_async()` gọi MCP discovery, không có fallback.

### Fix C1 — mcp/client.py

K áp dụng 2 sửa đổi:

1. **`_normalize_stdio_config()`** — rewrite `python`/`python3` → `sys.executable`, inject `PYTHONPATH=<agentic_rag_gemini>`, pass through critical env vars (PATH, USERPROFILE, HF_TOKEN, ...)

2. **try/except quanh `get_tools()`** — graceful fallback: nếu MCP discovery fail, log warning + return `[]`. Graph vẫn build được với in-process tools (`pgvector_search`). Retriever skip MCP-only intents; grader catches missing ToolMessage.

7 unit tests mới trong `test_phase3_mcp_client.py`:
- substitution python/python3 → sys.executable
- PYTHONPATH injection
- non-stdio transport untouched
- explicit env không bị override
- fallback to [] on error
- recovery after failure
