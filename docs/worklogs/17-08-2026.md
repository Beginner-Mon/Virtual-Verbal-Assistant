và model trả lời không giống persona. Giả thuyết ban đầu: phần thông tin +

**Đọc code thì giả thuyết đó chỉ đúng một phần, và không phải phần quyết định.**

nguyên nhân chính là prompt **gán identity hai lần** và **tự tuyên bố persona là
hạng hai**. Đó là tranh chấp thẩm quyền, không phải khối lượng — sửa được với 0
token thêm, 0 LLM call thêm.

## Vì sao không tách 2 node

Synthesizer đang stream từng token (`synthesizer.py:322-342`, `asyncio.sleep(0)`
ở `:337` là load-bearing). Node styling thứ hai không thể phát token đầu tiên
trước khi node content chạy xong → TTFT từ 1 LLM call thành 2 call nối tiếp, trên
đường có timeout 35s. Lợi thế recency mà nó mua được, mua bằng ~250 token voice
card đặt cuối prompt.

## Grader đã làm hỏng cái gì (Owner hỏi)

Grader không sinh chữ, nó chạy regex rồi **dán thêm** — `grader.py:371` dán block
cảnh báo lên đầu, `:410` dán `_UNAUTHORIZED_DISCLAIMER` xuống cuối.

Hỏng thật nằm ở **vòng lặp**, không ở câu trả lời đó:

```
grader → {"final_answer": modified}          grader.py:385-388
  → main.py:506 đọc final_state["final_answer"]   ← bản ĐÃ bị dán
  → main.py:515 write_session_turn(assistant_answer=...)
  → session_store.py:276 bảng messages, :287 Redis STM
  → lượt sau: memory node → synthesizer.py:308 → AIMessage trong prompt
  → model bắt chước "câu trả lời trước của chính mình"
```

Đoạn văn mẫu do regex dán vào trở thành câu mẫu cho lượt sau. Giọng phai dần theo
từng lượt. Grader không làm hỏng câu hiện tại — **nó bơm văn mẫu vào lịch sử, và
lịch sử là thứ dạy model cách nói ở lượt sau.**

## Ràng buộc quyết định thiết kế

`persona` **không** nằm trong `_PUBLIC_COLUMNS` (`handler.py:53`) — cố ý, vì nó
là system prompt. Nên UI string không thể đi ké đường persona.

→ **Cột public riêng**: `ui_strings` JSONB (migration `006`). `persona` ở lại
server, `ui_strings` ra browser.

Soạn ở đúng một chỗ — `personas/<slug>.md`, section `## UI Strings`, cùng cú
pháp `key: "value"` với `## Safety Templates` nên **dùng chung parser**
(`_parse_safety_templates` → đổi tên `_parse_key_values`).

```
personas/<slug>.md ──_load_persona──▶ persona["ui_strings"]
      ├── sync_personas_to_db.py ──▶ characters.ui_strings ──▶ catalog ──▶ frontend
      └── get_ui_string() ─────────▶ error_handler / main.py
```

`sync_personas_to_db.py` ghi cả hai chỗ **trong cùng một câu lệnh**, từ cùng một
dict — không thể lệch.

### `error_handler` nhận `config` — nhưng **có mặc định**

`error_handler_node(state)` một tham số. Nếu để tham số bắt buộc là **lặp lại
đúng lỗi đang làm 5 test grader đỏ** (`grader_node() missing 1 required
positional argument: 'config'`). Nên `config: RunnableConfig | None = None` —
LangGraph vẫn inject, caller cũ vẫn chạy.

### Gộp `DEFAULT_SAFETY_TEMPLATES` về một nguồn
