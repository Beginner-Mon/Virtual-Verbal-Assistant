# 26/07/2026 — Triệt tiêu T-pose trong CharacterViewer

## Bối cảnh
Owner yêu cầu khắc phục hiện tượng VRM luôn có khoảnh khắc T-pose (bind pose)
khi refresh, chuyển animation, hoặc đổi model. Wait time không giải quyết triệt để.

## Root cause (4 điểm hở)
| # | Tình huống | Cơ chế |
|---|-----------|--------|
| RC1 | Refresh | `loadMixamoAnimation()` / `loadAndRetargetBVH()` async mất vài trăm ms; trong lúc đó chưa có mixer → bind pose |
| RC2 | Đổi animation | Cleanup `stopAllAction()` chạy TRƯỚC, clip mới load SAU (async) — khoảng trống 0 action |
| RC3 | Pause (debug) | `action.stop()` — PropertyMixer restore original state → bind pose |
| RC4 | Đổi VRM model | `useLoader` suspend → fallback null → model mới mount, retarget lại idle từ đầu (async) → bind pose |

**Nguyên tắc bất biến**: từ lúc VRM visible, luôn có ≥1 action weight > 0. Mọi transition là crossfade event-driven, không bao giờ "stop → chờ async → play". Visibility gate thay wait time.

## Decisions chốt bởi Owner
- **D1**: Pause = debug-only → giữ nguyên stop(), không invest.
- **D2**: Fade = **0.3s**.
- **D3**: Model switch → **loading overlay** (chấp nhận blank/spinner), không giữ model cũ (`startTransition` dropped).

## Thực hiện

### 1. Clip cache (`src/lib/animationCache.ts` — file mới)
- `Map<"vrmUrl|animUrl", Promise<AnimationClip|null>>` — dedupe in-flight, tái sử dụng resolved clip.
- Failed/empty loads evicted để retry được.
- `THREE.Cache.enabled = true` (fetch-level dedupe).

### 2. CharacterViewer.tsx — crossfade state machine
- **Mixer per VRM**: tạo 1 `AnimationMixer` mỗi model, chỉ `stopAllAction()` khi teardown.
- **Animation load effect**: giữ action hiện tại chạy đến khi clip mới sẵn sàng; nếu `isPlaying` → crossfade 0.3s (`prev.fadeOut` + `action.fadeIn`), sweep fadingOut trong `useFrame` (weight → 0; stop + uncache). First-action path: `setEffectiveWeight(1)` ngay lập tức (không fade — tránh bind pose trong fade).
- **Generation counter** (`loadGenRef`): invalidate stale resolves; clip vẫn cache cho lần sau.
- **Visibility gate**: `<primitive visible={revealed} />` — `revealed` = false từ mount; set `true` sau `mixer.update(0)` trong async callback (pose đã apply mới reveal). **Event-driven readiness, không phải wait time.**
- **`key={vrmUrl}`**: remount sạch model cũ ngay, reset revealed + refs, hiện spinner overlay đến khi model mới posed.
- **Pause/play/reset effects**: giữ nguyên semantics (debug path).

### 3. CharacterViewer — loading overlay
- `viewerReady` state lái bởi `onReady(boolean)` từ VRMCharacter.
- Spinner CSS (`border-violet-400/30 border-t-violet-400 animate-spin`) overlay absolute khi `!viewerReady`.
- Hiện khi initial load hoặc model switch; ẩn ngay sau `revealed && onReady(true)`.

### 4. Fix pre-existing build errors (để unblock verify)
- `LipSyncController.ts:26`: `Uint8Array` → `Uint8Array<ArrayBuffer>` (TS 6.0 generics drift).
- `CharacterViewer.tsx:421`: `hemisphereLight skyColor` → `color` (@types/three 0.184 prop rename).
