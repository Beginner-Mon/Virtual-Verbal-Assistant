## 5. Live debug session (chronological)

A long sequence of UI/backend bugs Owner hit while testing. Many turned into actual product fixes.

### 5.1 CORS preflight 405 (browser blocked POST /chat)
**Symptom**: "Failed to fetch" in browser console, backend log shows `OPTIONS /chat 405 Method Not Allowed`.
**Root cause**: FastAPI had no `CORSMiddleware`. Browser preflight rejected before POST.
**Fix**: Add `CORSMiddleware(allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])` in `api/main.py`. **DEV ONLY** — Phase 7 must lock origins.

### 5.2 DB schema drift — missing `updated_at` column
**Symptom**: 500 on `GET /sessions?user_id=user_123`. Log: `UndefinedColumnError: column "updated_at" does not exist`.
**Root cause**: `init_schema.sql` was updated to include `updated_at` after the table was first created. `CREATE TABLE IF NOT EXISTS` doesn't ALTER existing tables.
**Fix**: Manual `ALTER TABLE conversations ADD COLUMN IF NOT EXISTS updated_at TIMESTAMPTZ DEFAULT now();` via psql. Same pattern for users table.

### 5.3 user_id as plain string vs UUID column type
**Symptom**: `asyncpg.DataError: invalid input for query argument $1: 'user_123' (invalid UUID...)`.
**Root cause**: UI sends `user_id="user_123"` (plain string) but DB schema has `user_id UUID REFERENCES users(id)`.
**Fix**: `db/session_store._to_uuid()` helper — try parse as UUID, else `uuid.uuid5(NAMESPACE_DNS, value)` (deterministic — same string always → same UUID). Applied at top of `list_user_sessions`, `load_session_messages`, `write_session_turn`.

### 5.4 FK violation when inserting conversations
**Symptom**: After 5.3 fix, INSERT into conversations failed because user UUID didn't exist in users table.
**Fix**: Auto-create user via `INSERT INTO users (id) VALUES ($1::uuid) ON CONFLICT (id) DO NOTHING` at top of `write_session_turn`.

### 5.5 ON CONFLICT missing UNIQUE constraint
**Symptom**: `there is no unique or exclusion constraint matching the ON CONFLICT specification`.
**Root cause**: Same as 5.2 — schema drift. `CONSTRAINT conversations_session_id_unique UNIQUE (session_id)` was added to schema file but never applied to existing table.
**Fix**: Manual `ALTER TABLE conversations ADD CONSTRAINT ... UNIQUE (session_id)`.

### 5.6 DELETE /sessions endpoint missing (UI threw 404)
**Symptom**: Backend log shows `DELETE /sessions/user_123/{id} 404 Not Found`.
**Root cause**: Endpoint never implemented. UI tried to call it.
**Fix**: Add `@application.delete("/sessions/{user_id}/{session_id}")` in `api/main.py` — DELETE conversations row + clear Redis STM.

### 5.7 Frontend api.js default URL wrong
**Symptom**: After CORS fix still "Failed to fetch".
**Root cause**: `ECA_UI/api.js` default fallback URL was `http://localhost:8000` (legacy ChromaDB orchestrator port, removed). Backend now on 8080.
**Fix**: Change default to `http://localhost:8080`. Also instructed Owner to `localStorage.clear()` to bust cached value.

### 5.8 Browser fetch streaming bug — `response.body.getReader()` returns 0 chars
**Symptom**: UI receives SSE response but renders empty message. curl from terminal works, `response.text()` in browser works, but `getReader()` returns done immediately.
**Diagnosis**: Likely antivirus or browser extension intercepting CORS chunked responses. Body is buffered server-side from browser perspective.
**Fix**: Rewrite `streamChat` in `api.js` with **two-layer fallback**:
- Layer 1: try `response.body.getReader()` streaming
- Layer 2: if reader returns 0 events, fall through to `respClone.text()` and parse all events at once
**Bonus UX (next iteration)**: replay token events with `await sleep(15ms)` between each in fallback path — typing animation simulates real streaming even when AV buffered the body.

### 5.9 `asyncio.create_task` GC footgun (TTS task silently disappearing)
**Symptom**: BackgroundTask for TTS never wrote result to Redis even though VieNeu `/synthesize` returned 200 OK. Poll loop timed out after 15s.
**Root cause**: Python docs warn:
> "Save a reference to the result of this function — to avoid a task disappearing mid-execution. The event loop only keeps weak references to tasks."
**Fix**: Module-global `_pending_tts_tasks: set = set()`. After `task = asyncio.create_task(...)`, do `_pending_tts_tasks.add(task)` + `task.add_done_callback(_pending_tts_tasks.discard)`. Strong ref until completion.
**Note**: Originally used FastAPI `BackgroundTasks.add_task` — that fires AFTER response closes, but our SSE response stays open polling for the task. Deadlock. Hence the switch to `asyncio.create_task` first.

### 5.10 VieNeu voice_path with Windows backslashes broke JSON encoding
**Symptom**: VieNeu received malformed JSON when persona MD's voice_path was `D:\Project_A\...\seele_en.wav`.
**Fix**: Updated `eca_default.md` to relative path `voices/seele_en.wav` (matches other persona files).

### 5.11 VieNeu returns `audio_file` (filename only) but UI expected URL
**Symptom**: `task_result` had `url: ""` because tasks.py read `result.get("audio_url")` but VieNeu returns `audio_file`.
**Fix**: tasks.py: read `audio_file`, prepend `http://localhost:5000/audio/` to build playable URL.

### 5.12 TTS timeout 15s too short for long Vietnamese
**Symptom**: VieNeu CPU TTS for 1342 chars Vietnamese = 15-20s. `httpx.TimeoutException` fired with empty `str()` → error log showed "VieNeu-TTS unavailable: vieneu_tts unavailable: " (empty reason).
**Fix**:
- `client.py`: timeout 15s → 60s
- `client.py`: error reason includes exception class name (`f"{type(exc).__name__}: {exc}"`) for diagnostics
- `main.py`: `_poll_speech_result(timeout=60)` to match

### 5.13 Language mismatch (LLM contradicted itself)
**Symptom**: User asked in English, AI responded "Xin lỗi, tôi sẽ trả lời bằng tiếng Anh." then continued in Vietnamese.
**Root cause**: Persona MD had behavioral rule "Use Vietnamese by default, switch to English if user writes English" + synthesizer prompt had ambiguous "Use Vietnamese if user query is in Vietnamese". Conflicting instructions → LLM confused.
**Fix**:
- Add explicit `_LANGUAGE_RULE` block at top of all synthesizer task prompts:
  > "Supported languages: ENGLISH and VIETNAMESE only. ... Detect query language. Respond in EXACTLY that language. Do NOT mix. Do NOT write preamble like 'I'll answer in English'. Start DIRECTLY with answer content."
- Remove language rule from `eca_default.md` behavioral_rules (synthesizer enforces it harder).

### 5.14 `load_session_messages` failed with `string indices must be integers`
**Symptom**: Clicking history session crashed backend.
**Root cause**: asyncpg returns JSONB columns as raw STRING by default. Code iterated `for m in messages:` then `m["role"]` → trying to index a character of the string.
**Fix**: In `load_session_messages`, `if isinstance(out["messages"], str): out["messages"] = json.loads(out["messages"])`.

### 5.15 Session reload created new session each time
**Symptom**: Reload browser → new session_id generated, old conversation lost.
**Root cause**: `let currentSessionId = activeSession || crypto.randomUUID ? crypto.randomUUID() : "session-..."` — JavaScript operator precedence parses as `(activeSession || crypto.randomUUID) ? new uuid : fallback`. `crypto.randomUUID` is a function = always truthy → always new UUID.
**Fix**: Explicit parens `activeSession || (crypto.randomUUID ? crypto.randomUUID() : "session-...")`. Also added localStorage persist for `activeSession` so reload preserves session.

### 5.16 UI persona dropdown
Added persona selector in header (`👤 Seele ▼` button) with dropdown showing 3 personas (Seele / ECA Buddy / Dr. ECA) with emoji + name + description + active ✓. Passed `selectedPersona` to `streamChat` via `personaId`. Session-only state (no localStorage).

### 5.17 UI TTS toggle 🔊
Checkbox next to 🔍 Web search. Sets `output_mode: "speech"` when checked. UI already had audio playback handler from earlier — speech_ready event auto-plays the URL.

### 5.18 Disclaimer position bug
**Symptom**: Disclaimer "*Câu trả lời chỉ mang tính chất tham khảo*" appeared in empty bubbles + at top of streaming response (before content arrived).
**Fix**: Gate disclaimer rendering with `{!isUser && msg.text && !msg.isStreamingText && (...)}` — only show after streaming complete + has content.

## 11. Lessons learned

1. **Browser fetch streaming + AV is unreliable for CORS chunked SSE** — production UI MUST have a `response.text()` fallback or use a proven SSE library. Don't rely on raw `getReader()`.
2. **asyncio.create_task without strong ref is a footgun** — even Python docs warn. Always store in a set + done_callback.
3. **CREATE TABLE IF NOT EXISTS doesn't catch schema evolution** — need defensive `ALTER TABLE ADD COLUMN IF NOT EXISTS` pattern OR a real migration tool (Alembic).
4. **PowerShell `>>` writes UTF-16 LE** — broke docker compose `.env` parsing. Cross-platform answer: use Python to write files.
5. **JavaScript operator precedence on `||` + ternary** is a classic — `a || b ? x : y` parses as `(a||b) ? x : y`, not `a || (b ? x : y)`.
6. **asyncpg JSONB columns are STRINGS by default** — need explicit `json.loads()` or register codec.
7. **httpx exceptions sometimes have empty `str()`** — always log `type(exc).__name__` for diagnostics.
8. **LLM prompt conflicts cause meta-confusion** — "Use VN by default, switch to EN if..." in persona + "Use VN if query is VN" in task → LLM contradicts itself. Have ONE source of truth, placed prominently.
9. **TTS CPU inference scales linearly with text length** — 15s default timeout is fine for <500 chars, breaks at 1000+. Set generously.
10. **Disclaimer/footer in React must guard on content + streaming state** — otherwise renders for empty bubbles + wrong position during stream.
