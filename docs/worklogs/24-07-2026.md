# 24/07/2026 — Bug fix: Biểu cảm không hoạt động + mắt đảo dọc

## Bối cảnh
N test Phase A trên seele.vrm (model mặc định): DevPanel trigger happy/sad/...
không thấy biểu hiện; mắt di chuyển theo chuột nhưng kéo lên → nhìn xuống và
ngược lại. K được giao tìm root cause + sửa cả hai.

## Bug 1: Expressions không hoạt động — seele.vrm binds rỗng

**Root cause**: model file, không phải code.

- Parse JSON chunk của seele.vrm: tất cả 17 blendshape groups có `binds: []`.
  Mesh có 47 morph targets tên MMD tiếng Nhật nhưng VRM extension không
  reference tới morph nào.
- three-vrm v3.5.3 `_v0Import` chỉ tạo bind từ `schemaGroup.binds`. Binds rỗng
  → expression đăng ký với 0 binds → `applyWeight()` loop rỗng → vô hình.
- Capability detection trong `VRMExpressionAdapter` dùng `getExpression(name) != null`
  — bindless expression vẫn trả về object → pass, không warning → pipeline chạy
  ngầm nhưng không render.

**Xác nhận**: bronya.vrm Joy(3 binds), Angry(2), Sorrow(4), Fun(4) → trên bronya
emotion chạy. Blink/viseme group của bronya cũng 0 binds nhưng mesh thiếu
`extras.targetNames` → không sửa được bằng tên.

**Fix** (3 files + 1 file mới):

1. `AvatarProfile.ts`: thêm field `morphRepairMap?: Record<string, string>` —
   map channel → morph target name cho model có binds rỗng.
2. `profiles/seele.ts` (mới): override profile với repair map:
   ```
   happy:'にこり', sad:'哀', angry:'怒り', relaxed:'なごみ', surprised:'びっくり',
   blink:'まばたき', aa:'あ', ih:'い', ou:'う', ee:'え', oh:'お'
   ```
3. `VRMExpressionAdapter.ts`: method `repairBindlessExpressions()` — traverse
   mesh để tìm morphTargetDictionary, nếu expression bindless → add
   `VRMExpressionMorphTargetBind` theo tên. Chạy TRƯỚC capability detection.
   Thêm import `VRMExpressionMorphTargetBind` từ `@pixiv/three-vrm`.

## Bug 2: Mắt đảo ngược dọc (kéo chuột lên → nhìn xuống)

**Root cause**: sign convention mismatch.

- three-vrm v3.5.3 `VRMLookAt` convention: `pitch = altitudeFrom - altitudeTo`
  (target trên đầu → altitudeTo > 0 → pitch âm). **NEGATIVE pitch = look UP**.
- Xác nhận kép: `VRMLookAtBoneApplier.applyYawPitch` (xem source module.js)
  pitch < 0 → `euler.x = -map(-pitch)` → euler.x âm → gaze hướng +Y = lên.
- `EyeController.setMouse`: mouse up (ny=+1) → `mousePitch = +12°` → pitch
  dương → look DOWN → ngược dấu.
- Trái/phải đúng vì model group xoay 180° Y triệt tiêu convention (yaw dương
  = model-left = screen-right).

**Fix**: `EyeController.ts` — negate pitch trong `setMouse` và `setWander`:
`mousePitch = -clampUnit(ny) * PITCH_MAX_DEG`. Cập nhật doc comment ghi rõ
three-vrm pitch convention.
